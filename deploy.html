Deploy the contracts

This page deploys both Pokepvp contracts from your own wallet, in the only order that works: the PokepvpNode NFT first, then the $PVP token — whose constructor sends the 600,000,000 PVP mining reserve straight to the NFT contract — and finally links the token into the NFT with setToken. Mint is open by default on the NFT contract. Every transaction is signed in your wallet; this page never asks for a seed phrase or private key.

Not connected. Connect the owner wallet to begin.
01

Deploy PokepvpNode (NFT)

The creature collection: 10,000 supply, five editions (Starter free 1-per-wallet, Bronze 0.000284, Silver 0.000709, Gold 0.00142, Diamond 0.00426 BNB), every node mines $PVP per second with era halving. No constructor arguments.

Waiting.

02

Deploy $PVP token

Fixed supply of 1,000,000,000 $PVP. The constructor takes the PokepvpNode address from step 01 as the mining reserve: 600,000,000 PVP (60%) goes straight to the NFT contract, 400,000,000 PVP (40%) to your wallet.

Waiting — deploy PokepvpNode first.

BscScan ↗
03

Link the token (setToken)

Points the NFT contract at the $PVP token from step 02 so claims can pay out of the mining reserve. One transaction; the page verifies pvpToken() afterwards.

Waiting — deploy steps 01 and 02 first.

04

Set metadata base URI (optional)

tokenURI(id) returns baseURI + id + ".json". Point it at your uploaded metadata folder (must end with "/"), e.g. an IPFS CID folder holding 1.json, 2.json, … You can also do this later — minting and mining work without it.

Waiting — deploy PokepvpNode first.

Contract addresses

When the steps are done, copy these two addresses and send them back — they get wired into the site's POKEPVP_CONFIG in app.js so minting, mining stats and claims go live for everyone. Addresses are also kept in this browser, so you can reload this page without losing them.
